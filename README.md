# Online Book Store SQL Project

## Overview
A beginner-friendly SQL project using **MySQL** to analyze an online bookstore's books, customers, and orders.

## Database Tables
- **Books** — book details, genre, price, and stock
- **Customers** — customer information and location
- **Orders** — order dates, quantities, amounts, and related book/customer IDs

## Analysis
The project includes basic and advanced SQL queries to explore:
- Book genres, prices, and stock
- Customer locations and spending
- Order frequency and quantities sold
- Revenue and stock remaining

## Tools Used
- MySQL
- MySQL Workbench
- CSV files
